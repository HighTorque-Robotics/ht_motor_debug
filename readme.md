## 2. 高擎电机调试助手下载方式

1. 点击右侧的 **Release** 按钮，进入 Release 页面进行下载。
2. 支持的系统版本：
   - Windows 10 及以上版本
   - Ubuntu 20.04 及以上版本
3. 建议优先选择最新版本使用：
   - Windows 平台请选择文件名中带有 `win` 的版本；
   - Linux 平台请根据系统架构选择对应版本：`linux_aarch64` 或 `linux_x86_64`。
